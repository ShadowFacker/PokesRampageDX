# PokesRampageDX

Juego de navegador hecho en un solo archivo HTML: sobrevive oleadas con tu Pokémon, sube de nivel, evoluciona, megaevoluciona, pelea en Rampage.io, compite en la Clasificatoria 1vs1 (ligas Bronce, Plata, Oro, Amatista y Maestro) y vive en el rancho de Ditto.

**Jugar:** https://shadowfacker.github.io/PokesRampageDX/

## Cómo actualizar el juego
1. Entra a este repositorio en GitHub.
2. Usa **Add file → Upload files** y sube el archivo nuevo con el nombre `PokesRampageDX.html` (reemplaza al anterior).
3. Si cambias la música, sube también la carpeta `music/` (combate1, combate2, boss, final, giratina y granja en MP3).
4. Pulsa **Commit changes**. En 1–2 minutos la página ya tiene la versión nueva (si no la ves, recarga con Ctrl+F5).

## Créditos
- Sprites y retratos de Pokémon: [PMD SpriteCollab](https://sprites.pmdcollab.org/) (cargados en línea desde su repositorio).
- Efectos de ataques: [The Spriters Resource](https://www.spriters-resource.com/ds_dsi/pokemonmysterydungeonexplorersoftimedarkness/) — *Poison/Dragon Attack Effects* de PMD Exploradores del Tiempo/Oscuridad (ripeados por redblueyellow) y el pack *Attack Effects* de PMD Exploradores del Cielo.
- Iconos de objetos y cintas: [PokéAPI](https://pokeapi.co/) / [PokeSprite](https://github.com/msikma/pokesprite).
